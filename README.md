# Джарвел Upgrade

Текстовый travel-агент для **одного человека или группы 2–4 человек**. Вы описываете поездку своими словами — агент собирает договор, ищет живые предложения через [Tutu MCP](tutu-mcp.md) и показывает только те маршруты, которые проходят жёсткие проверки стыковки.

Это независимый хакатонный прототип, **не официальный продукт Туту**. Агент не бронирует и не принимает оплату: после выбора конкретного тарифа открывается Туту.

В коде сервис ещё называют SpeakFare GroupSync. На экране — **JARVEL Upgrade**.

Живой стенд: [jarvel-web-production.up.railway.app](https://jarvel-web-production.up.railway.app/).

## Зачем это

Обычный поиск билетов заточен под одного пассажира и один фильтр. Группе нужно сойтись в **одной точной точке** и уехать **одним общим сегментом**, не путая IST с SAW и не выдавая короткую самостоятельную пересадку за «успеете».

Джарвел делает три вещи, которых нет в чат-обёртке над поиском:

1. Превращает свободный текст в канонический договор поездки.
2. Проверяет хаб, окно ожидания, общий рейс и багаж **детерминированным Python**, а не красноречием модели.
3. Отдаёт ссылку на Туту только после явного клика по точному тарифу. Исходный `checkout_ref` браузер не видит.

## Для пользователя

1. Откройте [живой стенд](https://jarvel-web-production.up.railway.app/) или главную страницу локального запуска.
2. Напишите или надиктуйте, кто едет, откуда, где встречаетесь и куда дальше.
3. Нажмите **«Найти билеты»**.
4. Если агент нашёл безопасный вариант — кликните нужный тариф. Откроется Туту; цена и условия проверяются уже там.

Пример:

```text
Нас трое: Аня из Москвы (VKO), Илья из Петербурга (LED) и Саша из Екатеринбурга (SVX).
21 августа 2026 встречаемся именно в IST (не SAW) и вместе летим одним рейсом в Лондон (LHR).
Ждать 2–5 часов. Багаж не нужен.
```

Полный разбор экрана, статусов и ограничений — в [руководстве пользователя](agent/docs/USER_GUIDE.md). Кратко: [FAQ](agent/docs/FAQ.md) и [безопасность](agent/docs/SAFETY_AND_LIMITS.md).

## Для разработчика

Код живёт в `agent/`. Python **3.13**, FastAPI, Jinja, vanilla JS, Three.js-глобус. Модель — через OpenRouter; инвентарь — публичный Tutu MCP.

```powershell
cd agent
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# заполните OPENROUTER_API_KEY; файл в Git не попадает
uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000/`.

| Режим | Команда | Когда |
|---|---|---|
| Живой агент | `uvicorn app.main:app --reload` | Есть ключ OpenRouter, нужен Tutu MCP |
| UI без сети | `uvicorn app.web:app --reload` | Демо-стенд с готовым сценарием |

Тесты (без ключа и без сети):

```powershell
python -m pytest -p no:xonsh tests -q -p no:cacheprovider
```

Дальше: [быстрый старт агента](agent/README.md), [архитектура](agent/docs/ARCHITECTURE.md), [HTTP API](agent/docs/API.md), [деплой](agent/docs/DEPLOY.md).

## Как устроено

```text
Текст или голос
    → InputSecurityGate
    → LLM выбирает plan_group_sync или plan_individual_trip
    → Python ходит в Tutu MCP, solver и SafetyGate
    → карточки в чате + маршрут на глобусе
    → клик по тарифу
    → сервер вызывает create_checkout_link
    → человек оформляет билет на Туту
```

Модель **не** вызывает поиск и checkout напрямую. Ей видны только два высокоуровневых tool. Низкоуровневые `search_*` и `create_checkout_link` исполняет Python. Опасный маршрут не получает ссылки на оформление — даже если пользователь просит «закрыть глаза».

## Границы MVP

Поддерживается: самолёт, поезд, автобус и их комбинации; один хаб и один общий финальный сегмент для группы; русский текст и диктовка; в чат уходит один проверенный вариант.

Не входит: оплата внутри Джарвела, отели как отдельный продукт, аккаунт, календарь, память между сессиями, прогноз задержек и «защищённая пересадка» без подтверждения в текущих данных MCP.
